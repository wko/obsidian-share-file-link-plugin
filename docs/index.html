Obsidian Link Sharer

Share Obsidian vault links with your team in Slack, Teams, and other apps

Perfect for teams working on a shared vault

When you're collaborating with others on the same Obsidian vault, you often want to point teammates to specific notes. This plugin lets you create clickable links that work in any messaging app.

You in Slack: "Here are the meeting notes: https://your-link.github.io/open.html?link=..."
Teammate: *clicks link* → File opens in their Obsidian

How it works

  1. Right-click any file in Obsidian and select "Copy Shareable Link"
  2. Paste the link in Slack, Teams, WhatsApp, email, or any app
  3. Teammates click the link and the file opens directly in their Obsidian

Features

Works everywhere

Standard HTTPS links that work in Slack, Teams, WhatsApp, email, and more

No server required

Links are stateless - all data is encoded in the URL itself

Private by design

No tracking, no analytics, no data collection

Open source

All code is open source and can be reviewed

Security

The plugin and redirect page are fully open source - you can review every line of code in the GitHub repository.

For additional control, you can host the redirect page yourself on your own domain or company server. Simply update the redirect URL in the plugin settings to point to your self-hosted version.

Get started

Install from Obsidian Community Plugins or download from GitHub.

Install in Obsidian View on GitHub

Requirements

  • Obsidian 1.0.0 or higher
  • GitHub Pages to host the redirect page (free)
  • Recipients need Obsidian installed with access to the same vault
